# tabline 에서 탭 구분 개선

1. 현황
tabline 의 탭들이 서로 잘 구분되지 않음.

2. 목표
탭 간 경계와 현재 탭을 더 쉽게 구분할 수 있도록 표시 개선 (구분자, 하이라이트 등).
- 어떤 상황에서 구분이 어려운지 보강 필요

3. 작업 노트
- 원인은 색: 비활성 탭 배경이 Normal/TabLineFill 과 같은 #111827, 현재 탭(#1f2937)과도 차이가 작았음.
- 탭을 폴더 모양으로 변경: 왼쪽은 곧은 변, 오른쪽은 Nerd Font 사선(U+E0B8)으로 끝나 탭 사이에 V자 홈이 생김.
  비활성 탭 #1f2937 / #9ca3af, 현재 탭 #7281c9 / #111827 bold (`TabLineTab*` 그룹).
- 첫 탭은 TabEnter 가 오지 않아 시작 직후 하이라이트가 비어 있던 문제를 `setup()` 에서 `tab_update()` 호출로 수정.
- 폰트 점검(fonts/ D2Coding NF): E0B0-E0B3 은 정상, E0B8-E0BB 는 2.5칸 폭, E0BC-E0D7 은 작은 아이콘이라 깨짐.
  터미널에서는 정상 표시되지만 neopp 는 글리프를 폭 그대로 그리므로 사선이 옆 칸을 덮을 수 있음.
  필요하면 폰트 패치 또는 neopp 에서 powerline 삼각형 직접 그리기로 해결.
- tabline 테스트 추가(사선 표시, 스크롤 표시 폭, 시작 시 하이라이트). 전체 테스트 통과.

- 2026-10-01: 사선 edge(\ue0b8)가 일부 환경에서 아래로 튀어나와 제거. edge 글리프 없이 직사각형 탭 + TabLineFill 배경의 공백 1칸으로 탭 구분.
