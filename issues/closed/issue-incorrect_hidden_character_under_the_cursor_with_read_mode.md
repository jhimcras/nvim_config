# Read 모드에서 커서 위치의 캐릭터가 보이지 않음

1. 현황
Read 모드에서 커서는 숨겨지지만 커서 위치의 캐릭터도 함께 보이지 않음.

2. 목표
커서는 보이지 않되 커서 아래 캐릭터는 원래 highlight와 함께 표시되어야 함.

3. 원인
`ReadModeHiddenCursor`의 전경색과 배경색을 모두 `Normal` 배경색으로 지정해,
블록 커서 아래 캐릭터의 전경색까지 배경색으로 덮어쓰고 있었음.

4. 해결
`ReadModeHiddenCursor`에서 전경색 지정을 제거하고 배경색에 `blend = 100`만
적용해 커서는 숨기면서 아래 캐릭터의 전경색은 유지하도록 수정.
`tests/spec/read_mode_spec.lua`에 커서 highlight가 캐릭터 전경색을 덮어쓰지 않는
회귀 테스트를 추가했으며 전체 테스트 스위트 통과.
